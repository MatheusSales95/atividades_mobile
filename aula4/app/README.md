Plataforma: Android e Web.

## Executar

Se a pasta tiver só o `lib/` (sem `pubspec.yaml`, `android/` e `web/`), gere o resto do projeto antes. O comando não sobrescreve o que já existe em `lib/`.

```bash
flutter create --template=app --empty --platforms=web,android .
```

Depois:

```bash
flutter pub get
flutter run
```
